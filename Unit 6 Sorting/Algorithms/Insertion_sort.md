## INSERTION SORT

### Algorithm

**Step 1:** Start with the second element (index 1) in the array, as the first element is trivially sorted.  
**Step 2:** Take the current element (let's call it `x`) and compare it to the elements before it.  
**Step 3:** If the element before `x` is greater than `x`, move that element one position to the right.  
**Step 4:** Continue comparing `x` with previous elements until the correct position for `x` is found.  
**Step 5:** Insert `x` in its correct position.  
**Step 6:** Move to the next element and repeat the process until the entire array is sorted.
