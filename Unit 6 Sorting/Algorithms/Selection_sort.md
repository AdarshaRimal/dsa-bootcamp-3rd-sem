## SELECTION SORT

### Algorithm

**Step 1:** Start from the first element of the array and assume it is the minimum.  
**Step 2:** Iterate through the rest of the array to find the smallest element.  
**Step 3:** If a smaller element is found, update the minimum index.  
**Step 4:** After scanning the entire array, swap the smallest found element with the element at the starting position.  
**Step 5:** Move to the next element and repeat the process for the remaining unsorted portion of the array.  
**Step 6:** Continue this process until the entire array is sorted.
