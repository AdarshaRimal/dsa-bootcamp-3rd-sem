## Searching in Binary Search Tree (BST)

**Step 1:** Start from the root node.  
**Step 2:** Compare the key with the node value.  
**Step 3:** If equal → element found.  
**Step 4:** If key < node value → move to the left child.  
**Step 5:** If key > node value → move to the right child.  
**Step 6:** Repeat until the element is found or the node becomes NULL.  
**Step 7:** If node = NULL → element not found.
