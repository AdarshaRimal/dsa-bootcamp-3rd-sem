## Insertion in Binary Search Tree (BST)

**Step 1:** Create a new node.  
**Step 2:** If the tree is empty → make the node root.  
**Step 3:** Start from the root.  
**Step 4:** Compare the key with the current node.  
**Step 5:** If key < node → move to the left child.  
**Step 6:** If key > node → move to the right child.  
**Step 7:** When a NULL position is found → insert the node.
